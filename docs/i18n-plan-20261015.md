# Internationalization plan (2026-10-15)

Owner-approved, shared with PowerSync (its `docs/i18n-plan-20261015.md` records
the finished Android side). First target language: **Spanish (`es`)**. Claude
drafts the first catalog; formats must stay easy for people to correct.

## Current state (survey, 2026-10-15)

- 21 embedded web templates (`internal/alexandria/web/templates`, ~730 lines),
  hard-coded `<html lang="en">`; help tips in `internal/alexandria/web/help.go`.
- ~130 elements of inline HTML in Go strings across 10 files in `internal/boox`
  (minutes, library browser, cleanup, audio recovery, admin, …).
- Text written onto tablets: `_Minutes` headings, text-note content, the Template
  Hub notice (`internal/boox/templatehub.go`).
- ~125 `http.Error` literals; most are machine-facing (BOOX API contract).

## Steps

1. **Move inline BOOX HTML into embedded template files.** No behaviour change;
   matches the "user-facing text in templates/help.go" rule.
2. **go-i18n v2** (`github.com/nicksnyder/go-i18n/v2`) with JSON catalogs
   (`active.en.json`, `active.es.json`; Weblate-native). Templates get a `t`
   function with the per-request localizer carried in page data, e.g.
   `{{t $.L "jobs.title"}}`; plurals via CLDR rules. Help tips become keys.
   Extract area by area: layout/navigation, Settings, Jobs, BOOX pages, help.
3. **What stays English:** BOOX/ksync API responses and other machine-facing
   errors, logs, model prompts (owner-editable in Settings already).
4. **Language choice:** a library setting → `Accept-Language`
   (`x/text/language` matcher) → English. `lang=` follows it. PowerSync already
   sends `Accept-Language`.
5. **Text written onto tablets** follows the library language. Minutes *content*
   follows the recording's language via the prompt.
6. **Dates and numbers** per locale (`x/text/message` for numbers; per-language
   date layouts).
7. **Guards:** test that every `t` key exists in the English catalog and none
   is orphaned; template scan that fails on bare text nodes; a pseudo-locale for
   layout overflow.
8. **Weblate** (self-hosted) once both catalogs exist.

## Conventions

Product and feature names are never translated (Alexandria, PowerSync, BOOX,
Audio Note Minutes, Template Hub). Title Case applies to the English catalog
only; Spanish headings use sentence case. Spanish uses informal *tú*.
