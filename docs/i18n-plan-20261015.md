# Internationalization plan (2026-10-15)

Owner-approved, shared with PowerSync (its `docs/i18n-plan-20261015.md` records
the finished Android side). First target language: **Spanish (`es`)**. Claude
drafts the first catalog; formats must stay easy for people to correct.

## Current state (survey, 2026-10-15)

- 21 embedded web templates (`internal/alexandria/web/templates`, ~730 lines),
  hard-coded `<html lang="en">`; help tips in `internal/alexandria/web/help.go`.
- ~130 elements of inline HTML in Go strings across 10 files in `internal/boox`
  (minutes, library browser, cleanup, audio recovery, admin, …).
- Text written onto tablets: `_Minutes` headings, text-note content, the Template
  Hub notice (`internal/boox/templatehub.go`).
- ~125 `http.Error` literals; most are machine-facing (BOOX API contract).

## Steps

1. **Move inline BOOX HTML into embedded template files.** No behaviour change;
   matches the "user-facing text in templates/help.go" rule.
2. **go-i18n v2** (`github.com/nicksnyder/go-i18n/v2`) with JSON catalogs
   (`active.en.json`, `active.es.json`; Weblate-native). Templates get a `t`
   function with the per-request localizer carried in page data, e.g.
   `{{t $.L "jobs.title"}}`; plurals via CLDR rules. Help tips become keys.
   Extract area by area: layout/navigation, Settings, Jobs, BOOX pages, help.
3. **What stays English:** BOOX/ksync API responses and other machine-facing
   errors, logs, model prompts (owner-editable in Settings already).
4. **Language choice:** a library setting → `Accept-Language`
   (`x/text/language` matcher) → English. `lang=` follows it. PowerSync already
   sends `Accept-Language`.
5. **Text written onto tablets** follows the library language. Minutes *content*
   follows the recording's language via the prompt.
6. **Dates and numbers** per locale (`x/text/message` for numbers; per-language
   date layouts).
7. **Guards:** test that every `t` key exists in the English catalog and none
   is orphaned; template scan that fails on bare text nodes; a pseudo-locale for
   layout overflow.
8. **Weblate** (self-hosted) once both catalogs exist.

## Conventions

Product and feature names are never translated (Alexandria, PowerSync, BOOX,
Audio Note Minutes, Template Hub). Title Case applies to the English catalog
only; Spanish headings use sentence case. Spanish uses informal *tú*.

## Built (2026-10-15, evening; deployed as `-i18n1`)

Steps 1–3 and the guard from step 7, with these design changes from the plan:

- **Message IDs are the English text** (gettext style), not invented keys:
  `{{t "Recognition Jobs"}}`. Templates stay readable and a missing translation
  falls back to English. The English catalog `internal/alexandria/i18n/locales/active.en.json`
  is generated and serves as the Weblate source file.
- **`t` is bound per request** on the cloned layout (no localizer in page
  data). `th` renders a message that carries its own inline markup, so a
  sentence isn't split around a link; `tip` translates help popovers.
- Values become named placeholders (`{{t "Page {{.Number}}" "Number" .Number}}`);
  a single argument or a `"Count"` pair picks the plural form.
- Go-side text: page titles translate at render time (`web.Verbatim` marks
  notebook/book names that must not be looked up); redirect notices carry
  their count in `notice_n`; `i18n.M` marks Go strings; `web/messages.go` lists
  values printed through `t` (job states, run labels, kinds, provider status).
- **Language choice:** Settings → Account language picker (per-browser cookie
  `alexandria_lang`) → `Accept-Language` → English. The library-wide language for
  text written onto tablets is still step 5.
- **Guard:** `TestCatalogsCoverEveryMessage` extracts every message (templates,
  Go patterns, help tips, registry) and fails when any language lacks a
  message or a plural form, or keeps one nothing uses — so rewording English
  fails until every language follows. `I18N_UPDATE=1` regenerates English.
  `TestPreviewPagesRenderInSpanish` renders every preview in Spanish.
- Tools: `scripts/i18n-wrap.py` (wraps template text, flags sentences with
  values for hand rewrites) and `scripts/i18n-merge.py` (joins fragments split
  by inline markup into one `th` message).

Spanish: 893 messages (25 plural), drafted by Claude with a shared glossary,
machine-checked for placeholders, markup and plural forms; **needs native review**.

Follow-up (`-i18n2`): stored job/page details translate at display time via
`td` (`web/details.go`: exact sentences plus "prefix: reason" patterns; unknown
text shown as stored); job-state chips and two slash headers translated; tables
use `overflow-wrap: break-word` + `hyphens: auto` instead of `anywhere`, so
Spanish words no longer split mid-word; the wrapper is idempotent and flags lone
words between values. **Markup safety:** the catalog test fails if any
translation's tags, attributes or placeholders differ from English, so
contributed translations can't add links, scripts or layout changes.

Known gaps: ~29 sentence fragments remain where text sits beside template
values; free-text details stored in the database (job failure details, older
notices built from errors) stay as written; numbers and dates are still
English-formatted (step 6); text written onto tablets is step 5; default model
prompts stay English by design.
